First cathul/polka release, based on upstream v0.1.22.

- One container includes FB2 → EPUB3 conversion for email delivery, controlled by the administrator. Uses Polka's existing SMTP account and each user's saved recipient address.
- Email subject and attachment name use author and title; the message follows the interface language.
- Personal OPDS Want to read shelf and independent web/OPDS search language preferences. Books without a language remain searchable.
- Safer INPX replacement preserves book identities, digest associations and user data; remembers the last successful server INPX path.
- Accurate two-way FB2 position synchronization between KOReader and the web reader. EPUB synchronization remains approximate and does not have the new FB2 reverse-position bridge.
- Progress removal, improved book actions, sticky header, account menu and footer; English and Russian UI.

## Install

Download `compose.yaml` into an empty directory. Create `.env` beside it with your existing library directory, bind address and port:

```dotenv
POLKA_BOOKS_PATH=/absolute/path/to/books
POLKA_BIND_IP=127.0.0.1
POLKA_BIND_PORT=12791
```

Then run:

```sh
docker compose pull
docker compose up -d
docker compose logs polka
```

The logs contain the initial administrator credentials. Image: `ghcr.io/cathul/polka:0.1` (Linux amd64/arm64). No separate converter container is needed. Configure SMTP in the admin interface; for Kindle, use a sender approved in the recipient's Amazon account.

Data persists in the Compose volume. Back up the entire data directory with Polka stopped before migrating an existing installation. Do not run `docker compose down -v` when retaining data. See the repository README for configuration and migration details.
