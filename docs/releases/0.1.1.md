OPDS search pagination fix.

- Encode Cyrillic and special characters in search links, preserving the query when moving between pages.
- Preserve literal plus signs in search queries rather than treating them as spaces a second time.
- Search language preferences and inclusion of books without a language are unchanged.

Image: `ghcr.io/cathul/polka:0.1.1`; `latest` is updated when this release is published.

Update an existing deployment without removing its data volume:

```sh
docker compose pull polka
docker compose up -d polka
```

For a new installation, download `compose.yaml` and follow the README.
